# 01.제품과완료기준 — 범위와 제외 항목

공통 컨텍스트 [`02.공통컨텍스트.md`](./02.공통컨텍스트.md) §2와 동일 원칙을 사람이 빠르게 보도록 정리한다.

## 1차 포함

- Frontend/Backend 저장소 연결 및 Commit 고정
- FE/BE AST 분석 · API 매핑 · Interaction Graph
- Scenario DSL · 입력 추천 · agent-browser 실행
- Backend 추적 · 바인딩 검증 · Evidence Package
- 건별/배치 실행 · HITL 승인
- (선택) Design Spec(PPT/이미지)·Excel/CSV를 **보조 Evidence**로 업로드·join·Catalog 참고

## 1차 제외 (Non-goals)

- 테스트 진척률 계산
- 개발자별 품질 점수 · 팀별 순위
- 미래 결함 예측
- 운영 Merge 자동 차단
- 운영 데이터 변경
- 모든 개발언어 지원
- DOM 또는 이미지 정보만으로 확정 시나리오 생성  
  ※ 기획 슬라이드는 hint/candidate만. 코드 Evidence join 없이는 승격 금지
- Excel/CSV 응답값의 자동 최종 승인 (HITL·Input Profile 승인 전 `reviewRequired`)
- LLM의 근거 없는 기대값 확정
- AI의 Pass/Fail·배포 최종 확정
- SVN·GitLab·Bitbucket 정식 수집기 (Local Path로 대체)

## 기술 우선순위

| 영역 | 1차 |
|---|---|
| FE 분석 | TypeScript / React / Next.js |
| BE 분석 | Java 17+ / Spring Boot 3.x |
| 브라우저 실행 | **agent-browser MCP** (Playwright MCP는 보완) |
| 플랫폼 | Python FastAPI · Next.js Console · Workers |
