# 14_23 — 로컬 모델 시나리오 생성 진행·완료 팝업

- 날짜: 2026-08-07
- Phase: 14.배치테스트
- 회차: 23
- 작업자/Agent: Codex
- 기준 포인터: `docs/index.md` 현재 Phase 14

## 1. 결론

장시간 로컬 모델 호출 중 버튼만 비활성화되던 UX를 생성 전용 CENTER 팝업으로 교체했다. 사용자가 `초안 만들기`를 누르면 선택 팝업은 즉시 사라지고, 진행 게이지·경과 시간·분석 범위·생성 방식·순환 안내 문구를 보여준다.

완료 응답을 받으면 같은 팝업이 완료 상태로 전환되고 `닫기`와 `테스트 시나리오로 이동`을 제공한다. 더 이상 생성 완료 직후 자동 이동하거나 기존 선택 팝업이 남지 않는다.

## 2. 진행 상태 계약

| 상태 | 화면 동작 |
|---|---|
| 시작 | 선택 팝업 즉시 닫기, 진행 팝업 열기 |
| 분석 범위 저장 | 실제 resource-selection 완료에 따라 기본 게이지 갱신 |
| 로컬 모델 응답 대기 | 경과 시간 기반 예상 게이지와 50개 고정 안내 문구 순환 |
| 대기 상한 | 서버 응답 전에는 92%를 넘지 않음 |
| 완료 | 실제 성공 응답 후에만 100%, 생성 건수와 이동/닫기 CTA 표시 |
| 빈 결과 | 오류 상태로 전환, 분석/Graph 확인 안내 |
| 요청 오류 | 오류 내용과 `다시 선택하기`/`닫기` 제공 |

현재 `POST /api/console/generate-scenarios`는 동기 응답이므로 모델 내부 token 단위의 실제 완료율은 제공하지 않는다. 따라서 팝업에 `예상 진행`을 명시하고 92%에서 대기하며, 서버 완료 응답만 100%로 취급한다.

## 3. 사용자 대기 경험

- AI pulse 아이콘과 작업 중 점 애니메이션을 추가했다.
- 근거 수집·화면/API 연결·입력/결과 매핑·형식 검증 등 50개 고정 문구를 3초 주기로 순환한다.
- 경과 시간, 선택한 분석 건수, `코드 근거 + 로컬 모델` 또는 `CSV + 코드 근거`를 표시한다.
- 진행 중 닫기 버튼은 제공하지 않아 요청 중단으로 오인하지 않게 하고, 오류/완료 상태에서만 닫을 수 있다.
- 진행 상태는 `aria-live`, 오류는 `role=alert`, 팝업은 `aria-busy`로 접근성 상태를 전달한다.
- D-009 공통 `ProgressBarType1`을 재사용한다.

## 4. React 품질 적용

- 생성 UI 상태를 하나의 typed state로 묶어 status/progress/result/error가 어긋나는 중간 렌더를 방지했다.
- 독립적인 분석 범위 저장 요청은 `Promise.all`로 병렬 처리한다.
- 프로젝트별 로컬 모델 생성은 모델 과부하를 피하기 위해 의도적으로 순차 실행한다.
- 1초 타이머는 진행 중에만 활성화하고 상태 변경/unmount 시 정리한다.
- 완료 후 자동 router 이동을 제거하고 사용자가 CTA를 선택하게 했다.
