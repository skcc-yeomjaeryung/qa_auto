- 기준 포인터: `docs/index.md` 현재 Phase 14

## 1. 결론

모든 메뉴 목록에서 반복 노출되던 AI 어시스턴트 안내 영역을 제거했다. 전체 건수, 선택 건수, 현재 페이지, 화면별 필터, 검색, CSV 내보내기·가져오기, 선택 삭제와 빠른 정렬은 `CommonDataTable`의 단일 도구막대로 병합했다.

테이블은 핵심 첫 데이터 열을 색과 굵기로 강조하고, 등록/수정 일시와 프로세스 열을 각각 184px·196px로 고정한다. 나머지 데이터 열은 공통 기준으로 화면 여유 폭을 나눠 쓰며 각 헤더 구분선을 드래그해 넓힐 수 있다. 이 계약은 화면별 열 너비 속성 없이 공통 컴포넌트만 소유한다.

## 2. 공통 테이블 계약

적용 화면은 프로젝트, 분석, 테스트 시나리오 그룹, 실행 이력, HITL, 증적, 스케줄링, 모델 관리, Agent 모니터링이다.

| 항목 | 공통 동작 |
|---|---|
| 상단 도구막대 | 왼쪽에 전체·선택·조회·페이지, 오른쪽에 필터·검색·CSV·삭제·정렬 배치 |
| AI 안내 | 목록마다 같은 문구를 반복하던 AI 어시스턴트 배너를 렌더링하지 않음 |
| 핵심 열 | 첫 데이터 열은 파란색·굵은 글씨, 다른 데이터 열보다 넓은 기본값 사용 |
| 데이터 열 | 여유 폭을 공통 계산으로 배분하고 헤더 구분선 드래그로 직접 조절, 더블클릭으로 초기화 |
| 고정 열 | 등록/수정 일시 184px, 프로세스 196px, 프로세스 버튼은 한 줄 유지 |
| 행 밀도 | 기본 행 38px, 다중 정보 행은 필요한 만큼만 확장 |
| 태그 | capability·분석 대상·핵심 상태는 짧은 색상 태그로 표시 |
| 스크롤 | 문서 가로 넘침 없음, 좁은 폭에서는 테이블만 가로 스크롤, 수직 스크롤은 CENTER가 소유 |

분석 결과의 긴 문장은 `화면`, `컴포넌트`, `Endpoint`, `화면 완료`, `서버 완료`, `확인`, `변경` 태그로 바꿨다. 첫 행 높이는 149px에서 53px로 감소했다. 모델 capability는 보라·파랑·초록·주황 계열 태그를 순환 적용하고 정상 여부는 상태 배지로 유지한다.

## 3. 팝업 공통 구조와 Figma 반영

Figma MCP로 지정 노드를 확인해 다음 기준을 반영했다.

- `2762:78956`: 14px 중심 정보 계층, 40px 테이블 행, 필터·목록·하단 행동 구조를 공통 테이블 밀도 기준으로 사용했다.
- `2471:21438`: 제한된 팝업 면적에서 탭과 고정 footer로 정보를 전환하는 구조를 실행 증적 팝업에 적용했다.
- 실행 증적 팝업은 `AI 관측 요약`, `실행 단계`, `증적` 탭을 사용하고 header/footer를 고정해 이중 수직 스크롤과 하단 CTA 가림을 피한다.

AI 표현은 모든 목록을 차지하는 설명 배너가 아니라 실행 관측·추천처럼 실제 AI 기능이 있는 문맥에만 남긴다.

## 4. Cursor MCP → Codex MCP

기존 `.cursor/mcp.json`의 안전한 로컬 실행 항목을 프로젝트 범위 `.codex/config.toml`로 변환했다.

| 서버 | Codex 등록 | 확인 |
|---|---|---|
| `next-devtools` | `npx -y next-devtools-mcp@latest` | enabled · 설정 파싱 완료 |
| `agent-browser` | `/Users/a11123/.local/bin/agent-browser mcp --tools core,network,react` | enabled · 설정 파싱 완료 |

Codex 앱·CLI·IDE는 같은 Codex MCP 설정 형식을 사용한다. 새 MCP 도구가 현재 작업의 도구 목록에 바로 나타나지 않으면 Codex 앱을 재시작하거나 새 작업을 연 뒤 사용한다. Cursor JSON은 자동 호환되지 않으므로 Codex TOML 형식으로 변환해 관리한다. Secret 값은 설정·문서·로그에 복사하지 않았다.
