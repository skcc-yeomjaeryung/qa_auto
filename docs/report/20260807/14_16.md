# 14_16 — 브라우저 세션 finally 종료·증분 분석 프로젝트 카드 계획

- 날짜: 2026-08-07
- Phase: 14.배치테스트
- 회차: 16
- 작업자/Agent: Codex
- 기준 포인터: `docs/index.md` 현재 Phase 14

## 1. 이번 단계에서 한 일

1. 실제 시나리오 실행 Python 함수의 agent-browser 종료가 정상 흐름 끝에서만 호출되는 상태를 확인했다.
2. 공개 `execute_scenario`가 내부 실행 함수를 `try/finally`로 감싸도록 분리했다.
3. 실행 성공, 실행 중 예외 모두 같은 세션에 `close`를 한 번 호출하도록 했다.
4. cleanup 호출 자체가 예외를 내더라도 원래 실행 결과나 주 실패를 덮어쓰지 않도록 best-effort 정리 함수를 추가했다.
5. 사용자 동의가 없어 브라우저를 열지 않은 요청은 호출자가 넘긴 재사용 세션을 닫지 않도록 유지했다.
6. 런타임 화면 탐색 경로는 이미 `try/finally`를 사용하고 있어 중복 수정하지 않았다.
7. 동기화 직후와 메인 대시보드 프로젝트 카드에서 변경 파일·영향 시나리오·권장 다음 행동을 보여주는 증분 분석 UX를 계획 문서로만 정리했다.
8. 이번 회차에는 증분 분석 API·데이터·Frontend 화면을 구현하지 않았다.

## 3. 실행·검증

- 최초 시스템 Python 검증은 사용자 Library bytecode 캐시 쓰기 권한과 PATH의 `pytest` 부재로 실행되지 않았다.
- 저장소 가상환경과 `/private/tmp` bytecode 캐시로 재실행했다.
- 실행 명령:

```text
PYTHONPYCACHEPREFIX=/private/tmp/qa-auto-pycache .venv/bin/python -m py_compile \
  app/skills/browser_execute/script/execute_run.py \
  tests/test_browser_execute_phase09.py

PYTHONPYCACHEPREFIX=/private/tmp/qa-auto-pycache .venv/bin/pytest -q \
  tests/test_browser_execute_phase09.py \
  tests/test_session_precondition_execution.py

PYTHONPYCACHEPREFIX=/private/tmp/qa-auto-pycache .venv/bin/pytest -q

PYTHONPYCACHEPREFIX=/private/tmp/qa-auto-pycache .venv/bin/pytest -q \
  tests/test_component_contract_phase07.py::test_api_build_contract_after_pipeline \
  tests/test_input_recommend_phase08.py::test_pipeline_includes_recommend
```

- 관련 경로 관측 결과: `27 passed, 1 skipped, 1 warning`.
- skip은 agent-browser CLI·로컬 Sample FE가 필요한 기존 live test 조건이다.
- warning은 기존 Starlette `httpx` deprecation 안내다.
- Python 구문 검증이 완료됐다.
- Backend 전체 회귀 관측 결과: `208 passed, 6 skipped, 2 failed, 1 warning`.
- 전체 회귀의 실패 2건은 `test_api_build_contract_after_pipeline`, `test_pipeline_includes_recommend`이며, 생성 목록 첫 시나리오에 `customerId`가 없다는 기존 Pipeline/시나리오 선택 경로다. 단독 재실행에서도 같은 2건이 재현됐다.
- 두 실패 경로는 이번 변경의 `execute_scenario` 호출과 세션 cleanup을 거치지 않는다. 이번 범위 밖이므로 수정하지 않고 관측 사실을 남긴다.
- Ruff는 가상환경에 설치되어 있지 않아 실행하지 못했다.
- `git diff --check` 전체 결과에는 기존 사용자 작업 파일의 trailing whitespace가 관측됐으며 이번 변경 파일과 무관해 수정하지 않았다.
- 화면을 구현·변경하지 않았으므로 이번 회차에는 agent-browser Console 관측을 수행하지 않았다.
