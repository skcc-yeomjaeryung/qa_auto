# 14_20 — 공통 table-center-bottom 정렬·선택 CTA·HITL 정보 경량화

- 날짜: 2026-08-07
- Phase: 14.배치테스트
- 회차: 20
- 작업자/Agent: Codex
- 기준 포인터: `docs/index.md` 현재 Phase 14

## 1. 결론

테이블 내용이 짧을 때 목록 컨테이너가 CENTER 중간에서 끝나고 고정 footer 위에 큰 공백이 남던 문제를 공통 `CommonDataTable`에서 해소했다. 테이블 shell이 CENTER의 남는 높이를 채우고 pagination이 bottom CTA 바로 위에 정렬된다. 화면별 footer 위치나 테이블 높이 속성은 추가하지 않았다.

테스트 시나리오 그룹 목록에는 체크박스 선택 기반 보라색 `선택 N개 그룹 일괄 실행`을 bottom 결정 CTA로 추가했다. 선택이 없으면 비활성화되고, 선택 후 활성화된다. 여러 프로젝트를 섞어 선택하면 기존 실행 계약에 따라 실행하지 않고 같은 프로젝트 선택을 안내한다.

## 2. 공통 레이아웃 개선

| 영역 | 적용 계약 |
|---|---|
| TOP 탭 | 현재 화면 탭은 보라색 배경·흰색 텍스트와 아이콘으로 명확히 구분 |
| CENTER | 목록이 짧아도 공통 테이블 shell이 footer 직전까지 높이를 채움 |
| TABLE toolbar | 검색 label의 grid 상속을 차단해 돋보기와 입력값을 한 줄 중앙 정렬 |
| BOTTOM | `PageStickyFooter`만 결정 CTA를 소유하고 CENTER 콘텐츠와 겹치지 않음 |
| RIGHT | 상세 정보는 우측 drawer 탭으로 분리, header의 긴 제목과 닫기 버튼이 충돌하지 않음 |

## 3. 시나리오 그룹 실행 CTA

- 그룹 목록의 체크박스 선택값을 실제 하위 시나리오 ID 목록으로 변환한다.
- `선택 0개 그룹 일괄 실행`은 비활성화 상태로 노출한다.
- 그룹 선택 시 `선택 1개 그룹 일괄 실행`으로 즉시 활성화한다.
- 실행 전 기존 계정·권한 확인 팝업과 같은 프로젝트 검증을 그대로 사용한다.
- 그룹 상세 화면의 `선택 N건 테스트 수행` 계약은 유지한다.

## 4. HITL 목록·상세 경량화

기존 HITL 표의 그룹, 시나리오 ID, 실행 ID, 관측 요약 등은 우측 상세에서 확인하도록 목록에서 제거했다. 목록은 다음 세 가지 문맥만 먼저 보여준다.

1. 보라색 굵은 글씨의 시나리오 한글명과 업무 분류
2. 자동 실행 상태
3. 화면·스냅샷·누락 여부를 나타내는 증적 태그

등록/수정 일시와 프로세스 열은 공통 계약대로 유지한다. bottom에는 단일 선택일 때만 활성화되는 `선택 1건 증적 검토` 결정 CTA를 추가했다. 다중 선택은 삭제 용도로 유지하며 증적 검토는 한 실행씩 수행한다.

우측 증적 drawer는 다음을 보강했다.

- 활성 탭: 보라색 배경·흰색 글씨
- 시나리오 한글명: 보라색 굵은 글씨
- 긴 그룹명: 닫기 버튼 영역을 침범하지 않고 자연스럽게 줄바꿈
- Evidence Package: 설명과 action 버튼을 세로로 분리, 버튼 내부 불필요한 줄바꿈 제거

## 5. 검증

| 검증 | 결과 |
|---|---|
| Frontend production build | PASS · 17 routes · TypeScript/Lint 완료 |
| 시나리오 1920px | table bottom 820px = footer top 820px · body 가로 overflow 0 |
| 검색 필드 | `display:flex` · 돋보기와 input이 32px 필드 안에서 한 줄 정렬 |
| 선택 CTA | 0개 비활성 → 1개 선택 후 보라색 CTA 활성 |
| HITL 목록 | 데이터 열 7개 → 핵심 3개 · 행 48px · 시나리오 강조색 적용 |
| HITL bottom | table bottom = footer top · 선택 1건 검토 CTA 활성 확인 |
| 상세 탭 | 활성 배경 `rgb(98, 92, 255)` · 텍스트 흰색 |
| 증적 action | 704px 가용 폭 · 버튼 overflow 0 · 설명/버튼 column 정렬 |
| 1280px | body 가로 overflow 0 · CENTER 수직 scroll 소유 · footer action wrap |
| 브라우저 로그 | error 0 · warning 0 |

위 PASS는 구현 빌드와 화면 기술 검증 결과다. 최종 품질 Pass/Fail과 배포 판단은 담당자 HITL 범위로 남긴다.
