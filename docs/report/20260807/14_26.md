# 14_26 — 대시보드 프로젝트 카드 장식·세션 환영 문구

- 날짜: 2026-08-07
- Phase: 14.배치테스트
- 회차: 26
- 작업자/Agent: Codex
- 기준 포인터: `docs/index.md` 현재 Phase 14

## 1. 결론

대시보드 `내 프로젝트` 카드의 비어 있던 우측 공간에 파스텔 프로젝트 폴더 일러스트를 낮은 불투명도로 배치했다. 프로젝트명은 카드의 첫 시선이 머무르도록 크기·굵기·색 대비를 높였다.

히어로 인사말은 프론트 규칙 데이터 50개 중 하나를 사용자 세션마다 선택한다. 같은 세션의 화면 이동·새로고침에서는 문구를 유지하고 새 세션에서 다시 선택한다.

## 2. 구현

| 영역 | 적용 내용 |
|---|---|
| 카드 장식 | `project-folder.svg` 파스텔 폴더·문서·체크 표현, 장식 이미지로 접근성 트리 제외 |
| 배치 | 카드 우측 하단 absolute 배치, pointer event 차단, 본문보다 낮은 z-index |
| 불투명도 | 기본 16%, hover 23%, 1180px 이하 13% |
| 프로젝트명 | 19~22px responsive, 800 weight, navy 색상, 장식 영역 전까지 최대 폭 제한 |
| 환영 문구 | `dashboardGreetings.ts`의 고정 문구 50개 |
| 선택 규칙 | Web Crypto 기반 무작위 선택, 사용자별 sessionStorage에 현재 세션 문구 보존 |
| 안정성 | 첫 렌더 기본 문구 제공, 유효한 규칙 문구만 재사용 |
