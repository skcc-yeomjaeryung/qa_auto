## 1. 장애 원인

- 모델 프로필은 SQLite에 저장됐지만 외부 모델 API Key는 서버 메모리에만 보관됐다.
- 서버 재시작 시 `hasApiKey=false`가 됐고, 과거 Health Check의 `정상` 상태만 남아 저장된 것처럼 보이는 모순이 있었다.
- 1차 Keychain CLI 입력은 장문 Secret을 128자로 잘라 저장해 무결성 확인에서 실패했다.
- 불완전 Keychain 항목을 제거하고 운영체제 Keychain API를 직접 사용하는 `keyring` 저장 경로로 교체했다.

## 5. 수용 계약

- 외부 모델 API Key는 운영체제 자격증명 저장소에 보관한다.
- 프로필 SQLite·API 응답·화면·로그에는 API Key 원문을 남기지 않는다.
- 수정 화면은 저장된 Key를 다시 채우지 않고 `안전 저장됨` 상태만 제공한다.
- 재입력하지 않은 수정은 기존 Key를 유지한다.
- 외부 모델에 Key가 없으면 과거 `정상` 상태를 재사용하지 않고 `미확인 · API Key 등록 필요`로 표시한다.
- 저장 성공과 Health Check 성공을 구분하고 둘 다 확인된 경우에만 완료 안내를 제공한다.
