## 1. 결론

14_13에서 한시적으로 유지한 구 `planner/orchestrator/reviewer/reducer` compatibility package를 완전 제거했다. `corev2`는 만들지 않았고, Plan은 `core/planning`, 실행은 `core/execution`, Review/Reduce는 `core/quality`, 외부 facade는 `core/runtime` 하나로 확정했다. 구 import는 0건이며 전체 회귀를 통과했다.

코드 단위 검사에서 끝내지 않고 public Bank of Anthos 저장소와 Cymbal Bank 실행 환경을 신규 프로젝트로 등록해 연결→자동 분석→23개 시나리오 생성→실제 브라우저 실행→실행 이력/Evidence→HITL→Agent Trace까지 관통했다.

## 2. 제거한 중복 경계

- `backend/app/core/planner/`
- `backend/app/core/orchestrator/`
- `backend/app/core/reviewer/`
- `backend/app/core/reducer/`

이 package는 14_13 구현을 공식 경로로 re-export하던 wrapper였으며 별도 업무 로직은 없었다. 삭제 전 AST import 영향도와 테스트를 확인했고, 삭제 뒤 Python 150개 파일을 다시 파싱해 구 import 0건을 확인했다.

공식 책임은 다음과 같다.

```text
PlatformRunnerAdapter
  → AgentRuntime
      → planning.Planner
      → execution.Orchestrator
      → quality.Reviewer / quality.Reducer
      → observability.AgentTrace
```

## 5. Agentic Core 관통 결과

Agent Trace `PLAN-8b1a0424761e`는 `wf_scenario_dsl`의 `project_context_discover → scenario_dsl → scenario_narrate` Plan, Skill 실행, Reviewer, Reduce, Workflow 완료를 한 화면에 표시한다.

모델 결정기는 `balanced` 정책으로 `llama3.2`를 78.75점에 선택하고 임베딩 후보를 capability/context/structured-output 부족으로 제외했다. 선택된 로컬 endpoint가 연결되지 않아 narrative LLM은 실행되지 않았고 결정론 fallback으로 생성이 완료됐다. 현재 환경에는 API key가 준비된 public LLM profile이 없어 외부 모델 호출 성공을 허위 보고하지 않는다. public 저장소와 public 실행 대상의 실데이터 관통은 완료했다.

## 6. Evidence·HITL

`RUN-ba3206ba5256`에서 11개 스크린샷과 13개 DOM snapshot을 수집했다. 실행 이력 drawer에서 이미지 확대, 개별 다운로드, 현재 증적 ZIP, Evidence Package ZIP을 확인했다.

최종 케이스는 잘못된 입금액을 브라우저가 POST 전에 차단하는 안전 케이스다. 따라서 Backend request/response/network가 없는 상태를 `partialEvidence`와 `missing_data`로 표시하며 증거를 발명하지 않는다. Evidence Package는 artifact 16개, masked 13개, retention 2026-09-06을 표시했다.

HITL 화면은 프로젝트→그룹→시나리오 ID→한글명→실행 ID 순으로 대상을 구분하고 우측 drawer에 판정 근거와 누락 증적을 표시했다. 최종 승인/반려는 수행하지 않았다.
