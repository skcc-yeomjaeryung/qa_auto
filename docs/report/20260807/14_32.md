## 5. 수용 계약

- 리포트의 증적 건수는 manifest 건수와 같아야 한다. 이미지가 아닌 증적도 목록으로 축약하지 않고 내용을 확인할 수 있어야 한다.

- 안전 정책 차단은 업무 실패와 구분한다. `실행하지 않음`과 `실행했지만 실패함`을 같은 빨간 오류로 표시하지 않는다.
- 데이터 변경 실행은 사용자의 명시적 1회 승인 없이 자동으로 우회하지 않는다.
- FLOW의 그래프와 상세는 탭으로 분리하고, 페이지·그래프·상세에 중첩 세로 스크롤을 만들지 않는다.
- Complete는 기술 실행 상태이며 HITL Pass를 의미하지 않는다.
