## 3. 신빙성 보정

- Component Contract를 scenario 단위로 제한해 다른 시나리오 입력 오염을 차단했다.
- 로그인 계정은 `environment.loginId` / `environment.loginSecret`만 사용하고 secret을 마스킹했다.
- client-side validation은 Backend 호출 불필요 상태로 분리했다.
- 외부 공개 대상은 `external_network_only`로 표시해 파일 누락과 구분했다.
- 클릭 직후 modal 표시를 조건 기반으로 기다리고 `표시 확인 1/1건`을 수집했다.
- UI composition scenario는 존재하지 않는 입력 단계를 발명하지 않고 source→destination 증적으로 패키징했다.
- HITL·타임라인의 외부 대상 표기를 `증적 일부 누락`에서 `외부 대상 관측 범위`로 교정했다.
