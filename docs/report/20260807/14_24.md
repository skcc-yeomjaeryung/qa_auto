## 1. 결론

모델 관리에 사내 추론/Vision·임베딩 모델과 OpenAI GPT-5·GPT Image 2 프로필을 함께 표시하고, 프로젝트 생성/수정 여정에 `모델 설정` STEP을 추가했다. 프로젝트는 기본 `AI 자동 추천` 또는 역할별 고정 모델을 선택할 수 있으며, 실행 시 Agent Trace가 `후보 평가 → 선택 → 실제 provider 호출 영수증`을 분리해 기록한다.

GPT Image 2는 화면 인식 VLM이 아니라 이미지 생성·편집 역할로 바로잡았다. PPT와 agent-browser 스크린샷 이해는 `vision` 입력을 지원하는 GPT-5 또는 사내 Qwen Vision을 사용한다.

## 2. 등록 모델

| 역할 | 프로필 | 상태 |
|---|---|---|
| 일반 추론·분석 | 기본 로컬 모델 · Qwen 3.6 27B | 정상 |
| 임베딩·검색 | 기본 임베딩 · Qwen3-VL-Embedding-8B-FP8 | 정상 |
| 고급 추론·요약·Vision | OpenAI · GPT-5 고급 추론·Vision | 프로필 등록 · API Key 필요 |
| 이미지 생성·편집 | OpenAI · GPT Image 2 생성·편집 | 프로필 등록 · API Key 필요 |

외부 API Key는 모델 프로필/SQLite/로그에 저장하지 않고 현재 서버 메모리에서만 사용한다. 이번 검증에서는 대화에 노출된 키를 재사용하지 않았으므로 OpenAI 두 프로필의 실제 Health/호출은 의도적으로 수행하지 않았다.

## 3. 프로젝트 모델 설정 UX

- 생성 STEP을 5개에서 6개로 확장했다.
  1. 프로젝트 이름
  2. 모델 설정
  3. 저장소 연결
  4. 실행 환경
  5. 품질 보강 자료
  6. 최종 등록 확인
- 생성 기본값은 `AI 자동 추천`이다.
- `역할별 모델 고정`을 선택하면 일반·임베딩·Vision·고급·이미지 생성 역할별 등록 모델을 지정한다.
- 공통 CENTER 팝업에서 모델명·ID·capability를 검색하고 필수 capability로 후보를 제한한다.
- 외부 모델에 Key가 없으면 `API Key 필요` 사유와 함께 선택 불가로 표시한다.
- 수정 화면에서는 모든 STEP을 처음부터 다시 밟지 않고 상단 STEP을 직접 눌러 해당 정보만 수정한다.
- 현재 STEP은 보라색 배경과 흰색 제목으로 명확하게 표시한다.

## 4. 등록 가이드

- 모델 등록 drawer에 기존 대시보드 QA 로봇을 재사용했다.
- Endpoint·Model ID·Capability·API Key 보관 정책을 짧은 키워드로 안내한다.
- `vision = 화면/PPT 이해`, `image_generation = 새 이미지 생성·편집`을 명시한다.
- GPT-5와 GPT Image 2 빠른 입력 버튼을 제공한다.
