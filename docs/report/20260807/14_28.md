## 1. 이번 단계에서 한 일

- 테스트 시나리오 일괄 실행의 SSE 집계에 완료·성공 관측·실패 관측·취소 건수를 추가했다.
- 시나리오 그룹 목록의 `실행 관측` 셀에 공통 진행률 컴포넌트를 연결해 대상 건별 게이지와 집계 건수를 표시한다.
- 분석 결과 계약에 실제 분석 대상 파일 수·완료 수·오류 수·진행률을 추가하고, Frontend/Backend analyzer가 파일 처리 때마다 progress snapshot을 기록하도록 했다.
- 서비스의 progress watcher가 실제 snapshot만 저장소에 반영해 목록의 `분석 진행` 게이지가 파일 건별로 증가한다. 경과 시간 기반 가짜 진행률은 사용하지 않는다.
- 분석 목록은 표시 중일 때 조용히 다시 조회해 백그라운드 분석 완료 건수가 갱신되도록 했다.
- 의존관계 그래프 CTA를 보라색 주 행동으로 격상했다.
- FLOW viewport의 가로·세로 스크롤과 방향키·Page Up/Down·Home/End 탐색을 복구했다.
- Figma TableBlock의 행 높이·구분선·상태형 bar-chart cell 의도를 현재 공통 테이블 밀도에 맞게 반영했다.
- AI가 표시하는 성공/실패 수는 기술 관측 집계이며 HITL 최종 판정과 분리했다.
