## 1. 이번 단계에서 한 일

- 메뉴·헤더·대시보드·프로젝트·분석·테스트 시나리오·플로우·실행 이력을 한국어 중심으로 정리하고 Pilot/프로토타입 문구를 제거했다.
- 대시보드를 한눈 KPI·다음 작업 바로가기로 단순화했다.
- 프로젝트 메뉴를 연결 중심 UX로 재구성했다. 연결 시 자동 sync·분석, 연결 완료 문구, 체크박스 일괄 분석, 분석/수정/삭제 버튼을 제공한다.
- 분석 메뉴에 연결 저장소 분석 목록·3depth 리소스 트리·체크 제외·「테스트 시나리오 생성 시작」을 구현했다.
- 테스트 시나리오 메뉴에 서비스/거래 ID(PK)·Request/Response·일괄 실행·성공/백엔드/업무/화면 오류 구분을 추가했다.
- 플로우 메뉴에 컴포넌트 성공(초록)/실패(빨강) 테두리·입출력 수정·재시도를 추가했다.
- Backend에 `/api/console/*` 및 프로젝트/저장소 PATCH·DELETE를 추가했다.
