# 10_3 — Console UX: 프로젝트·분석트리·시나리오·실행·플로우 개선

- 날짜: 20260804
- Phase: 10
- 회차: 3
- 작업자/Agent: Cursor Agent
- 기준 포인터: docs/index.md 현재 Phase 10.Backend추적

## 1. 이번 단계에서 한 일

- 네비를 준비(대시보드·프로젝트·분석·테스트 시나리오 생성·플로우) / 관리(실행 이력·증적·HITL)로 재구성했다.
- 프로젝트는 로그인 사용자(`ownerUserId`) 기준으로 만들고, 연결 마법사(연결방식 → 경로/URL → 저장소 이름)로 저장소를 등록한다.
- 분석 화면은 저장소 이름 중심 목록 + 다크 소스 탐색기(아이콘·확장자·코드 미리보기 API)로 보강했다.
- 시나리오 상세 전용 페이지를 두고, agent-browser 동의 UI를 제거했다(플랫폼이 consent 강제).
- 실행 이력은 반분 레이아웃 대신 `/runs/[runId]` 전체 화면 + 시나리오형 내레이션 스텝으로 바꾼다.
- 플로우 노드 라벨을 변수명이 아닌 시나리오 단계명으로 표시하고, 클릭 시 INPUT/OUTPUT을 본다.
