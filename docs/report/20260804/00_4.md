## 1. 이번 단계에서 한 일

- Web Console을 LEFT(내비) / CENTER(작업) / RIGHT(컨텍스트) 3단 셸로 재구성했다.
- Figma Data Table kit을 참조해 시나리오 목록 표 뷰를 구현했다.
  - breadcrumb · header actions · filter chips · result count · sortable columns · row select · RIGHT detail
- Dashboard·placeholder 페이지도 동일 셸을 공유하도록 맞췄다.
- Kit의 purple accent는 기존 AI_TEST teal 브랜드로 매핑했다 (구조·컴포넌트 패턴은 kit 준수).
