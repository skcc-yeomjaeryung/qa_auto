## 1. 이번 단계에서 한 일

우측 컨텍스트 패널을 기본 접힘으로 두고, 접힘 시 DOM/그리드 공간을 할당하지 않아 CENTER를 전체 폭으로 쓴다. 프로젝트 메뉴는 좌·우 분할 레이아웃을 제거하고, Figma Data table kit 토큰 기준의 전체 폭 테이블을 메인으로 둔다. 「프로젝트 생성」은 우측 상단 CTA로 분리하고, 클릭 시 생성 전용 화면(이름 → Git 연결 → 확인)으로 이동한 뒤 목록으로 돌아온다. 행 프로세스 버튼은 프로젝트 분석 · 수정 · 삭제다.
