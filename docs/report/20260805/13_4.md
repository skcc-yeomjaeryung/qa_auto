## 1. 이번 단계에서 한 일

사용자가 지시한 4개 묶음을 구현하고, 남아 있던 Phase 13 Gate를 닫았다.

1. **개발환경 연결 필수 입력** — 프로젝트 등록/수정의 실행 환경 단계에서
   연결 URL(`https://cymbal-bank.fsi.cymbal.dev`) · 연결 BROWSER(`chrome`) ·
   연결 ID(`testuser`) · 연결 PASSWORD 를 필수로 받는다. 기본값을 채워두되 빈 값이면 저장을 막는다.
   비밀번호는 응답에 싣지 않고 별도 secret 저장소에만 두며, 화면에는 `등록됨(***)`만 보인다.
   실행 시 이 연결 정보로 agent-browser 로그인 게이트를 통과한다.
2. **분석 화면** — 저장소 분석을 그룹 카드가 아니라 평면 테이블로 바꿨다.
   전체 건수(현재 8건)·연결 저장소·분석 대상·결과 요약·상태·분석 완료 시각·프로세스가 한 화면에 보이고,
   행을 클릭하면 소스 탐색 상세로 이동한다. 체크박스·선택 삭제·화면 내 검색을 붙였다.
3. **테스트 시나리오 컨셉** —
   - 중복 제거: 결정론 서명 기반 제거 + 시스템 프롬프트(`dedupe_scenarios_system.md`) 기반 LLM 검토(규칙 재검증 통과분만 반영).
   - 입력 직접 바인딩: 실행기가 DOM을 탐색해 입력 컨트롤을 찾고, 연결 계정·화면 관측값·판단 순으로 값을 채운다.
     접근성 이름이 없는 입력은 DOM 순서와 마스킹(●●●) 관측으로 계정 입력을 판별한다.
   - 실행 요약: 단계 수·바인딩한 값·관측 결과를 한국어로 요약해 실행 상세와 흐름 헤더에 노출한다(LLM 미구성 시 결정론 폴백).
   - 증적: 화면 진입 · 입력 섬밋 직후 · 로그인 후 화면 · 결과 화면 스크린샷을 남기고 클릭하면 팝업으로 확대된다.
4. **플로우 화면** — 플로우 그룹 테이블 → 그룹 내 시나리오 테이블 → 단계 흐름 3단으로 정리했다.
   체크박스·선택 삭제·검색·실행 시각 등 타 화면과 같은 공통 컴포넌트를 갖췄고, 스크롤 없이 목록을 볼 수 있다.
5. **공통 시각 표기** — `frontend/lib/datetime.ts`의 공통 포맷으로 모든 목록·상세의 실행 시각을
   `yyyy-mm-dd hh:mm:ss` 로 통일했다(시나리오·플로우·실행 이력·증적·HITL·프로젝트 환경).
6. **테스트 정합성 복구** — 위 변경으로 드러난 기존 결함을 고쳤다.
   추천 ID 충돌(시나리오 간 덮어쓰기), Interaction Graph 노드 체인 누락(Phase 05 계약 미준수),
   시나리오 DSL 스키마에 없던 `assert_visible`/`assert_text`, 3단 플로우 반영 전 E2E.
