## 1. 이번 단계에서 한 일

GOODFOOD Dashboard Community 레이아웃 이식(10_8)을 이어, 아이콘/입력 크롬을 [Flexible Inputs Kit](https://www.figma.com/design/ZiSEA4AUYGNOxSUZCEhBbg/%E2%9A%A1%EF%B8%8F-Auto-Layout-Flexible-Inputs-%E2%80%93%C2%A0Kit--Community-?node-id=1025-8032)로 보완했다. 검색 필드는 Kit의 Icon Left 필드(radius·focus ring) 톤을 맞추고, 돋보기 글리프는 GOODFOOD `search.svg`를 유지했다. DashboardClient에서 실행 0건일 때 40/32/28%를 채우던 추정 도넛·품질 % 공식을 제거하고, 관측 API 수치만 쓰며 없으면 `missing_data`/빈 상태 UI로 표시하도록 고쳤다. 워크스페이스 primary/ghost/right-panel이 GOODFOOD 토큰을 상속하도록 셸 CSS를 보강했다.
