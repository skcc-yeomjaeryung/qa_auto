## 1. 이번 단계에서 한 일

Figma Dashboard Community(GOODFOOD) 셸·토큰·대시보드 그리드를 AI_TEST Console `frontend/`에 이식했다. 사이드바 우선 240px 레이아웃, Poppins/Noto Sans KR 타이포, 보라 계열 primary(#5A6ACF)로 AML 블루 그라데이션 배경을 제거했다. AppShell은 도메인 라우트·프로젝트 잠금·HITL/탭/우측 패널 로직을 유지한 채 GOODFOOD 내비 아이콘·헤더 검색 pill을 적용했다. DashboardClient는 mascot/figma-dash UI를 제거하고 프로젝트·실행 API 기반 카드 5종 그리드로 교체했다.
