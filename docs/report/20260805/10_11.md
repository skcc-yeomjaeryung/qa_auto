# 10_11 — 저장소 연결: Git URL만 · 트리 표시

- 날짜: 2026-08-05

- 회차: 11
- 작업자/Agent: Cursor Agent
- 기준 포인터: docs/index.md 현재 Phase 10.Backend추적

## 1. 이번 단계에서 한 일

프로젝트 저장소 연결에서 Frontend/Backend 하위 경로 입력을 제거했다. GitHub URL(또는 로컬 경로)만으로 저장소 루트를 `workspace` 역할로 등록·동기화하고, 연결 후 `GET /api/repository-sets/{id}/tree`로 실제 파일 트리를 보여 준다. bank-of-anthos처럼 FE/BE 폴더가 없는 모노레포도 연결 가능하다.

## 2. 변경·산출물

| 경로 | 목적 |
|---|---|
| `backend/app/services/repository_models.py` | `RepoRole.workspace` |
| `backend/app/services/console_models.py` | `repository` 단일 소스 Connect 계약 |
| `backend/app/services/console_service.py` | single-repo connect · set tree |
| `backend/app/api/repository_sets.py` | `GET /{set_id}/tree` |
| `frontend/components/ProjectsWorkbench.tsx` | 연결 UX 단순화 + 트리 |
| `frontend/components/CodeResourceTree.tsx` | `readOnly` 모드 |

## 3. 실행·검증

- `npx tsc --noEmit` — exit 0
- ConnectPairRequest `repository` only 파싱 관측
- Pass/Fail 단정 없음 · 실제 clone은 사용자 연결 시 확인
