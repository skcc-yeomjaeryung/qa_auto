# 13_1 — 건별 테스트 화면 관측 · 파일럿 샌드박스 기본 대상 Cymbal Bank 전환

- Phase: 13.건별테스트
- 회차: 1
- 작업자/Agent: Cursor Agent
- 기준 포인터: `docs/index.md` 현재 Phase = **13.건별테스트**

## 1. 이번 단계에서 한 일

1. Phase 13 건별 테스트 화면(`/scenarios/{id}`)을 실제 Console에서 열어 DOM·스크린샷으로 관측했다.
   - 최초 진입 시 500이 관측됐고, 원인은 dev 서버 2개가 같은 `.next` 빌드 디렉터리를 공유해
     생긴 캐시 손상(`Cannot find module './611.js'`)이었다. 중복 프로세스를 정리하고 캐시를 지워 복구했다.
2. 사용자 지시에 따라 **파일럿 샌드박스 기본 실행 대상**을 로컬 sample FE(`http://127.0.0.1:5173`)에서
   `https://cymbal-bank.fsi.cymbal.dev/home` 으로 전환했다. 기본값을 코드 SSOT 한 곳에 모으고
   Backend·Frontend·저장된 환경 레코드를 함께 정렬했다.
3. baseUrl에 진입 경로(`/home`)가 붙었을 때 URL이 중복되는 문제를 고쳤다.
   - health check가 `/home/home` 을 찍는 현상 → 절대 경로는 origin 기준으로 해석하도록 변경.
   - 시나리오 step navigate도 동일 규칙(`route_url`)으로 통일.
4. Cymbal Bank health check가 `CERTIFICATE_VERIFY_FAILED (self-signed certificate in chain)` 로 실패했다.
   curl은 성공(302)했고 httpx만 실패한 점에서 사내 프록시 루트 CA가 certifi 번들에 없는 상황으로 관측됐다.
   TLS 검증을 끄지 않고 **OS 신뢰 저장소(truststore)** 를 쓰도록 바꿔 검증 유지 상태로 `up`을 관측했다.
5. 화면 Guardrail 위반 2건을 고쳤다.
   - 여정 Type 2 스텝퍼 라벨이 서로 겹침(라벨 62px vs 스텝 폭 50px) → 스텝 최소 폭 확보로 겹침 0.
   - 주 CTA `추천값으로 실행` 이 CENTER 스크롤 영역 아래로 밀려 보이지 않음 → 실행 바를 sticky 처리하고,
     스크롤 없이도 미확인 항목을 알 수 있게 `확인 필요 N건` 점프 칩을 추가했다.
6. `npm run build` 가 실행 중 dev 서버의 `.next` 를 덮어써 500을 만드는 구조적 문제를 분리했다
   (build 전용 `.next-build`).
