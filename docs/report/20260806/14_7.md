## 4. 판정 및 데이터 이행 정책

- 과거 실행 증적은 수정하지 않는다. 원본 단계에 `error=server_error`·Flask Not Found가 있으면 잘못 저장된 `expected_met`보다 우선해 표시를 자동 실패로 보수 정규화한다.
- 신규 실행은 Flask 기본 404 문구까지 서버 오류 신호로 남긴다.
- 기존 시나리오 DSL은 재작성하지 않는다. 기존 회원가입 그룹은 직접 `/signup`부터 단계화되고, 새 동기화·분석 후 생성한 시나리오부터 실제 `#create-account-btn` 진입 단계가 포함된다.
- 기술 Complete를 HITL Pass로 승격하지 않았다.
