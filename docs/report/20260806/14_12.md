## 2. 데이터 흐름

```text
프로젝트 저장소·환경 연결
  → 선택: CSV/PPTX 업로드
  → extract → VLM OCR → embedding → local FAISS
  → Project Context manifest
  → Scenario workflow의 project_context_discover Skill
      ├─ found: 관련 청크 + Evidence ref + Graph/DOM/API + system prompt + LLM
      └─ not_found: 기존 Graph/DOM/API + system prompt + LLM
```

기존에 Scenario DSL·Narrate Skill 실행기는 있었지만 프로젝트 보조자료의 존재와 관련성을 먼저 판별하는 전용 Skill은 없었다. 이번 회차에 Capability, Skill, Workflow 선행 단계와 실제 입력 전달을 함께 추가했다.
