# docs/report — 날짜·회차 작업 요약

사람이 **어느 Phase의 몇 번째 작업 단계**인지 바로 인식하기 위한 요약 저장소다.

정식 Phase Gate 완료 보고는 [`../06.완료보고/`](../06.완료보고/)에 둔다.  
본 폴더는 세션/회차 단위의 진행 일기다.

## 규칙

Cursor Rule: [`.cursor/rules/03-post-report.mdc`](../../.cursor/rules/03-post-report.mdc)

```text
docs/report/YYYYMMDD/{phase}_{n}.md
예: docs/report/20260804/00_1.md
```

## 파일 본문 필수 섹션

1. 이번 단계에서 한 일  
2. 변경·산출물  
3. 실행·검증  
4. 다음 단계  
5. **핵심 근거** (왜 이렇게 요약했는지)
