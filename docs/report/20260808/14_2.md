# Phase 14 작업 보고 — 시스템 프롬프트 영어화·한국어 원본 보존

- 일자: 2026-08-08
- Phase: 14.배치테스트
- 범위: `backend/app/prompts` 런타임 시스템 프롬프트 영어화, 한국어 원본 백업, 모델 호환성 최적화, 회귀 검증

## 1. 변경 결과

- 런타임에서 로드하는 `*_system.md` 11개를 영어 지침으로 전환했다.
- 각 기존 한국어 원문을 동일 경로의 `*_system_KOR.md` 11개로 보존했다.
- `_KOR.md`는 변경 전 Git HEAD 원문과 바이트 단위로 일치한다.
- 런타임 프롬프트에는 한글 문자가 남지 않으며, 한국어 Console 출력이 필요한 필드는 영어로 `write user-facing values in Korean` 계약을 명시했다.
- 파일 경로·버전 주석·JSON 키·enum·evidence ref·secret reference는 유지했다.

## 2. 모델 호환성 최적화

- 소형·로컬 모델: 입력 순서 기반 결정적 체크리스트, exact identifier copy, schema-first, JSON-only 지침을 추가했다.
- 추론 모델: 근거 충돌을 비공개로 분석하고 chain-of-thought를 출력하지 않도록 고정했다.
- Vision 모델: 텍스트 영역 → 컨트롤 → 공간적 흐름 → unresolved 순서로 관측하도록 고정했다.
- Provider/model ID는 프롬프트에 하드코딩하지 않고 Core `ModelRegistry`/`ModelSelector` 책임을 유지했다.
- 공통 정책은 `backend/app/prompts/README.md`에 문서화했다.

## 3. 주요 Guardrail 유지

- Reachability is not success.
- 최종 Pass/Fail·승인·배포 판단은 HITL 책임이다.
- 근거 없는 route·selector·method·path·expected value 생성 금지.
- 로그인 계정은 `environment.loginId`·`environment.loginSecret` 참조만 사용.
- Secret·개인정보·마스킹 값 복원 금지.
- 문서 보조자료는 코드·DOM·Graph·Backend 계약과 join된 후보로만 사용.

- 기존 호출부는 계속 같은 `*_system.md` 경로를 사용하므로 런타임 API 변경은 없다.
