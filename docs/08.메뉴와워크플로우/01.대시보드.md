# 대시보드 Workflow

## 화면 목적

로그인 직후 프로젝트와 테스트 운영 상태를 한 화면에서 요약하고, 사용자가 다음 작업으로 바로 이동하도록 돕는다.
프로젝트가 없으면 프로젝트 등록을, 실행 이력이 없으면 테스트 시나리오 실행을 안내한다.

## 사용자 흐름

1. `TEST / 1` 또는 바로 로그인으로 `/`에 진입한다.
2. 내 프로젝트, 분석 변경, 시나리오·실행·HITL 검토 대기 건수를 확인한다.
3. 최근 7일 기술 관측 추이와 최근 실행 결과를 확인한다.
4. 프로젝트 카드 또는 빠른 작업을 통해 분석, 시나리오, 실행 이력, HITL로 이동한다.

## 코드·API 매핑

| 항목 | 값 |
|---|---|
| Route | `/` |
| 화면 | `frontend/components/DashboardClient.tsx` |
| API | `GET /api/dashboard/summary` |
| Workflow | 없음. 저장된 프로젝트·분석·시나리오·Run을 사용자 범위로 집계 |

성공률이 계산 가능한 표본이 없으면 `null`로 표시하며 임의의 0%나 100%를 만들지 않는다.
대시보드의 자동 실행 상태는 기술 관측이고 최종 품질 판정은 HITL에 있다.
