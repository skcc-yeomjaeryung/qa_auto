# 모델 관리 Workflow

## 화면 목적

분석·시나리오·화면 이해·임베딩 등 역할에 사용할 내부망/외부 OpenAI-compatible 모델을 등록하고,
Agentic Core가 capability와 운영 정책으로 안전하게 선택할 수 있게 한다.

## 제공 기능

- endpoint, API base, `/v1/models`, model ID, 내부/외부 배포 구분
- `chat`, `code`, `vision`, `embedding`, `tools`, `image_generation` Capability
- context window, structured output/tool 지원, 품질·비용·속도·신뢰도 점수
- Health Check와 endpoint가 제공하는 모델 목록 확인
- 프로젝트의 general·vision·embedding·advanced·image generation 역할별 자동 추천/수동 고정
- `auto`, `cost_saver`, `balanced`, `highest_quality`, `internal_only` 정책

## 코드·API 매핑

| 항목 | 값 |
|---|---|
| Route | `/manage/models` |
| 화면 | `frontend/components/ModelManagementWorkbench.tsx` |
| API | `GET/POST/PATCH/DELETE /api/models`, `POST /api/models/{id}/health-check` |
| Core | `ModelRegistry`, `ModelSelector`, `ToolRuntime` |

모델 profile은 SQLite에 저장한다. API Key 원문은 운영체제 Keychain에 저장하고 API 응답·SQLite·Trace에는
노출하지 않는다. 후보 선택 이벤트만으로 모델 사용량을 계산하지 않고 Provider 호출 완료 영수증을 사용한다.
