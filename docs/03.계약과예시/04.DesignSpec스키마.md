## 역할

사용자가 작성한 **UI 기획 슬라이드**(PPT/이미지/PDF)를 파싱해  
시나리오 설명·조작 힌트·Assertion **후보**를 제공한다.

주 경로(코드 AST · Interaction Graph)를 대체하지 않는다.

## 슬라이드 포맷

```text
TOP    : 서비스/거래 아이디 및 타이틀 (+ 조작 안내 문구)
CENTER : 화면 캡처 + 번호 annotation
RIGHT  : 번호별 컴포넌트명 · 노출/클릭 로직 설명
```

## 등급 규칙

| 상태 | grade | 허용 동작 |
|---|---|---|
| 파싱만 완료 | `hint` | 설명·semantic 후보 |
| Graph node 후보 매칭 | `candidate` | DSL step 초안 보강 |
| 코드 Evidence join + 정적/런타임 확인 | (상위 Evidence 신뢰도) | Contract/Locator 승격 가능 |
| join 실패 · 필드 부재 | `missing_data` | 추정 금지 · 사람 확인 |

Design Spec 단독 confidence 상한: **0.49**

## 금지

- 이미지만으로 Scenario DSL 확정
- RIGHT 영역의 기대 문구를 hard assertion으로 자동 확정
- Pass/Fail·배포 단정
