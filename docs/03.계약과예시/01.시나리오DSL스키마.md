## 역할

Interaction Graph를 **agent-browser MCP가 실행할 수 있는** 단계형 DSL로 고정한다.

## 필수 개념

- `source` / `destination` 화면·Route
- `inputs` + locator + events (`fill`, `blur`, `click` …)
- `steps` (navigate / fill / click / wait_for_response …)
- `assertions` (ui-binding 등)
- `evidencePolicy` (`screenshots`, `snapshots`, `network`, `browserRunner: agent-browser-mcp`)
- `hitlPolicy`

## 규칙

- Schema 검증 통과 전 저장 금지
- unresolved 항목은 추정으로 채우지 않음
- Runtime 기본 엔진은 agent-browser MCP
