# 03.계약과예시 — Interaction Graph 스키마

- Schema: [`schemas/interaction_graph.schema.json`](./schemas/interaction_graph.schema.json)
- 생성 Phase: [`../04.Phase실행바이블/05.InteractionGraph.md`](../04.Phase실행바이블/05.InteractionGraph.md)

## 역할

`A 화면 → 이벤트 → API → Backend → Response → B 화면 → Binding` 경로를  
Node/Edge + Evidence + Confidence로 표현한다.

## 대표 Node

`screen`, `component`, `input`, `event`, `frontend_api_call`,  
`backend_endpoint`, `request_dto`, `response_dto`, `route_transition`, `binding`, `assertion`

## 대표 Edge

`contains`, `triggers`, `calls`, `navigates_to`, `binds_to`, `asserts`, `branches_to`
