- 정책: [`../01.제품과완료기준/02.공통컨텍스트.md`](../01.제품과완료기준/02.공통컨텍스트.md) §2.1
- 의사결정: [`../02.아키텍처/03.의사결정기록.md`](../02.아키텍처/03.의사결정기록.md) D-006
- 사용 Phase: [`../04.Phase실행바이블/08.입력값추천.md`](../04.Phase실행바이블/08.입력값추천.md)

## 역할

사용자가 제공한 **Excel/CSV** 테스트데이터를 Catalog로 적재해  
서비스·거래 아이디 기준으로 INPUT 추천을 보강한다.

운영 DB 직접 조회를 대체하지 않으며, 응답 기대값의 자동 최종 승인을 하지 않는다.

## 권장 컬럼

```text
서비스/거래 아이디 | 요청 필드… | 응답/기대 필드… | 업무상태(선택)
```

## 승인 상태

| approvalStatus | 의미 |
|---|---|
| `draft` | 업로드·파싱만 |
| `reviewRequired` | 기본값. 추천 후보로만 사용 |
| `approved` | Input Profile / HITL 경로에서 배치 사용 가능 |
| `rejected` | 추천 제외 |

## 입력원 위치 (Phase 08)

```text
1) Fixture/Factory/Seed/Test code
2) 테스트 전용 Data API
3) FE/BE Schema · Validation
4) Test Data Sheet (Excel/CSV)   ← 본 계약
5) Best Practice Catalog
6) LLM semantic suggestion (+ Design Spec hint)
7) 사용자 입력
```

## 금지

- PII/Secret 평문 저장 (synthetic 또는 masked만)
- 미승인 응답값을 hard expected로 확정
- 식별자 무작위 생성으로 시트 대체
