# QA_AUTO AI 해커톤 5분 데모 영상 시나리오

## 1. 영상 목표

대형 SI 테스트의 반복 수작업을 **AI Agent가 코드 근거 기반 테스트 시나리오 초안, 실제 브라우저 실행,
증적·리포트 자동화**로 연결한다는 점을 5분 안에 보여준다.

핵심 메시지는 세 가지다.

1. 개발자가 엑셀에 시나리오·입력·예상 결과를 처음부터 수기로 만드는 시간을 줄인다.
2. 제3자 테스터의 반복 클릭과 증적 캡처를 자동 실행·예외 중심 검토로 전환한다.
3. AI가 최종 품질을 독단적으로 결정하지 않고, 코드·DOM·API·증적을 사람의 HITL 판단에 전달한다.

## 2. 촬영 전 준비

### 화면·데이터

- 해상도 `1920×1080`, 브라우저 zoom 90~100%, 알림·북마크·개인정보 숨김
- Console과 Backend를 기동하고 `/health`가 정상 응답하는지 확인
- 데모 로그인 `TEST / 1`
- 프로젝트 입력 예시
  - 이름: `AI Bank Code-to-E2E Pilot`
  - 설명: `Frontend·Backend 코드 기반 관통 테스트 자동화`
  - 태그: `AI Agent, E2E, Hackathon`
  - 모델 정책: `AI 자동 추천 · 균형`
  - 저장소: `https://github.com/GoogleCloudPlatform/bank-of-anthos.git`
  - branch: `main`
  - 실행 URL: `https://cymbal-bank.fsi.cymbal.dev`
  - Browser: `chrome`
  - 로그인 ID/Password: 파일럿 Secret 저장소에서 주입, 영상에는 마스킹된 입력만 노출
- 시나리오 생성과 실행은 사전에 한 번 실제 완료해 둘 것
- 촬영 당일 사용할 Scenario Set, 시나리오, Run ID, 리포트가 존재하는지 확인
- 대표 시나리오는 로그인 선행조건과 A→API→B가 모두 보이는 입금 또는 송금 업무를 선택
- 리포트 HTML/JSON과 Evidence ZIP 다운로드가 가능한지 확인

### 편집 원칙

- 분석·생성 대기 시간을 임의 완료 상태로 조작하지 않는다. 실제 시작과 실제 완료를 각각 촬영해 점프컷한다.
- 클릭 위치에는 0.5초 강조 원을 사용하고, 표의 ID보다 업무명·상태·근거를 크게 보여준다.
- 화면 전환마다 먼저 “이 화면은 무엇을 제공하는가”를 한 문장으로 말한 뒤 조작한다.
- Secret, API Key, Password 원문, Cookie, Authorization, 개인 경로는 블러 또는 crop 처리한다.
- 자동 관측의 `expected_met`는 “기술 기준 충족”으로 읽고 최종 Pass로 말하지 않는다.

### Scene 01 — 썸네일과 30초 오프닝 `00:00~00:30`

#### 00:00~00:05 썸네일

- 비주얼: 코드, Agent, 브라우저, 리포트 아이콘이 한 줄로 연결

#### 00:05~00:18 문제 정의

내레이션:

> 대형 SI 현장에서는 개발자가 테스트 시나리오와 입력·예상 결과를 엑셀에 수기로 만들고,

```text

반복 클릭·결함 등록
```

> QA_AUTO는 AI Agent가 Frontend와 Backend 코드를 분석해 A 화면부터 API와 B 화면까지

**화면 기능 한 줄:** “프로젝트 범위와 모델, 저장소, 실행 환경, 보조자료를 단계별로 연결하는 시작 화면입니다.”

- STEP 2: `AI 자동 추천`과 `균형` 정책 선택

- 화면 강조: 연결 Progress가 동기화→Frontend/Backend 자동 분석으로 이어지는 장면
- STEP 4: 실행 URL, Chrome, 역할, ID, 마스킹 Password 입력 후 Health 확인
- STEP 5: CSV/PPTX 보조자료 영역을 보여주고 자료가 없으면 그대로 다음 단계
- STEP 6: 연결 결과 카드에서 프로젝트·모델 라우팅·저장소·자동 분석·실행 환경 확인

내레이션:

> 저장소 연결 즉시 코드 분석이 시작되고, Password는 화면과 Trace에 원문으로 남기지 않습니다.
> PPT와 CSV는 코드·DOM·API와 일치할 때만 보조 근거로 사용합니다. 마지막 STEP 6에서 연결 결과를 확인합니다.

편집: 실제 연결·분석 시작 장면 뒤 완료 장면으로 타임랩스 전환

화면 자막:

```text

예상 증적 = 단계별 DOM·화면·Network·Backend Trace
```
