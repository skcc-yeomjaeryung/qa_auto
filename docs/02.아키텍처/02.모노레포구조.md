# 02.아키텍처 — 모노레포 구조

`qa_auto/` 가 메인 프로젝트 루트다.  
플랫폼 실행 단위는 **`frontend/`** · **`backend/`** 이다 (D-011).  
`backend/` 내부는 **NH_AML 정렬 SDD** (D-012).

분석 **대상** 샘플은 `sample-targets/` 에 둔다 (플랫폼 frontend/backend 와 별개).

> **2026-08-04:** 구 `backend/` 전량 삭제. Phase 00b 로 재구축.  
> 아래 트리는 **목표 SSOT** 이다.

```text
qa_auto/                         # 메인 루트
  frontend/                      # Next.js Web Console (:3000)
  backend/                       # Python FastAPI + SDD (:8000) — 재구축
    app/
      api/
      core/                      # router planner orchestrator reviewer reducer
      langgraph_runtime/         # 공통 plan_execution_graph (Hub 아님)
      workflow_definitions/      # Workflow Hub
      skills/                    # Skill Hub
      agents/                    # Named Execution Boundary
      capability_definitions/
      schemas/
      services/                  # 비-agent CRUD (projects/repos) — Hub 우회 금지와 분리
    workers/                     # Skill script가 호출하는 중용량 analyzer
      frontend-analyzer/
      backend-analyzer/
      agent-browser-runner/
    tests/
  packages/
    contracts/
    adapter-sdk/
    test-data-catalog/
  sample-targets/                # 분석·매핑 대상 FE/BE 샘플
    customer-portal-fe/          # Vite React (:5173)
    customer-service-be/         # Spring Boot (:8080)
  infra/
  docs/                          # ★ 바이블 SSOT
  artifacts/
  scripts/
```

## 책임 경계

| 경로 | 역할 |
|---|---|
| `frontend/` | 플랫폼 Console UI |
| `backend/app` | API + SDD Runtime + Workflow/Skill Hub |
| `backend/workers/*` | Skill이 호출하는 analyzer/runner 외부 런타임 |
| `sample-targets/*` | Code-to-E2E 대상 저장소 |
| `packages/contracts` | JSON Schema SSOT 동기 |
