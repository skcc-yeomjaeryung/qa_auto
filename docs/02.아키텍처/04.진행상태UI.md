## 사용자 여정 (5단) ↔ Progress 매핑

플랫폼 주 여정. Progress Type 2 스텝퍼를 **프로젝트 헤더/마법사**에 기본 사용한다.

| # | 사용자 행동 | 스텝 라벨(권장) | Progress 상태 |
|---|---|---|---|
| 1 | 프로젝트 생성 | 프로젝트 | Empty → Progressing → Complete |
| 2 | 저장소(레포) 연결 | 저장소 | Empty → Progressing → Complete |
| 3 | 테스트시나리오 생성 진행 | 시나리오생성 | Progressing (분석·Graph·DSL) |
| 4 | 시나리오 목록 생성·확인 | 시나리오목록 | Complete(목록 준비) / Warning(unresolved) |
| 5 | 일괄·개별 테스트 실행 | 테스트실행 | Progressing → Complete / Error / Warning(HITL 대기) |

```text
프로젝트 → 저장소 → 시나리오생성 → 시나리오목록 → 테스트실행
```

- 현재 스텝: Icons `Progressing` 또는 Type 2 현재 점
- 완료 스텝: Icons `Check` + 연결선 filled
- 미착수: Icons `Empty` + 회색 연결선
- 실패/차단: Icons `Error` (기술 실행 실패·수집 실패)
- 주의/검토: Icons `Warning` (`reviewRequired`, unresolved, HITL 대기)  
  ※ Warning·Complete는 **고객 Pass/Fail 승인 단정이 아니다** (HITL 분리, D-004)

## 화면별 사용 규칙

| 화면 / 상황 | 권장 Type | Phase |
|---|---|---|
| 프로젝트 생성~실행 마법사·헤더 파이프라인 | **Type 2** (스텝퍼) | 01 → 06 → 13/14 |
| 시나리오 목록 행: 생성/실행 진행률 | **Type 1** | 06, 13, 14 |
| 건별 실행 중 스텝(A→API→B)·ETA | **Type 4** (Show Step) | 09, 13 |
| 배치 실행 요약 카드 | **Type 5** 또는 Type 1 | 14 |
| 세그먼트만 필요한 짧은 바 | Type 3 | 보조 |

## Agent 구현 절차 (필수)

```text
1) Figma MCP get_metadata(fileKey=HLWN6f7fxSVMIxoZtW6SIc, nodeId=799:98620)
2) 사용할 Type의 get_design_context / get_screenshot
3) Icons·Type 상태를 도메인 상태 enum에 매핑
4) 프로젝트 토큰·Next.js 컴포넌트로 이식 (REFERENCE 코드 그대로 붙여넣지 않음)
5) 완료 보고에 fileKey·nodeId·사용한 Type 기록
```

- 사용 전 사용자에게 Figma MCP 사용 여부를 확인한다.
- Progress의 Complete ≠ HITL 승인. 실행 기술 완료·생성 완료만 의미한다.

## 상태 enum (권장)

```text
empty | progressing | complete | error | warning | disable
```

| enum | Figma Icon | 의미 |
|---|---|---|
| `empty` | Empty | 미시작 |
| `progressing` | Progressing (+ Animation) | 진행 중·현재 스텝 |
| `complete` | Check | 해당 단계 기술 완료 |
| `error` | Error | 실패·중단 |
| `warning` | Warning | 검토 필요·부분 완료 |
| `disable` | Disable | 선행 미충족으로 비활성 |

## 금지

- Progress 없이 스피너/텍스트만으로 5단 여정·시나리오 실행 상태를 대체
- Complete 색을 “테스트 Pass / 배포 가능”으로 라벨링
- Figma kit을 열지 않고 임의 Progress 바 발명
