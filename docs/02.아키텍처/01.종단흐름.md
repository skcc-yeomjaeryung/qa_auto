# 02.아키텍처 — 종단 흐름

## 가치 사슬

```text
① 시나리오 생성
   저장소 연결
     (+ 선택: Design Spec / Excel·CSV 보조 업로드)
   → FE/BE 분석 → API 매핑 → Interaction Graph
   → Scenario DSL (+ Design Spec annotation join 후보)

② 실행 · 품질 재료
   입력 추천 (Fixture → Data API → Schema → Excel Catalog → Best Practice → LLM → 사용자)
   → agent-browser 실행 → Backend 추적 → 바인딩 검증 → Evidence

③ 운영 UI · HITL
   건별/배치 실행 → 관측 요약 → 고객 승인/반려/재실행
```

### Console 주 여정 (Progress UI)

```text
프로젝트 생성 → 저장소 연결 → 시나리오 생성 → 시나리오 목록 → 일괄/개별 테스트
```

진행·완료·스텝 상태는 Figma Progress Kit 필수: [`04.진행상태UI.md`](./04.진행상태UI.md) (D-009)

보조 입력원 규칙: [`../01.제품과완료기준/02.공통컨텍스트.md`](../01.제품과완료기준/02.공통컨텍스트.md) §2.1

## A→B 관통 (대표 시나리오)

```text
A 화면 /customers/search
  → 입력(fill) · 조회(click)
  → POST /api/customers/search
  → Spring Controller · DTO · Validation
  → Response
  → B 화면 /customers/{customerId}
  → UI 바인딩 검증
  → Evidence + HITL
```

상세 DoD: [`../01.제품과완료기준/03.파일럿완료기준.md`](../01.제품과완료기준/03.파일럿완료기준.md)
