## 실행 중

1. 기존 코드를 먼저 읽고 중복 구현하지 않는다.
2. 사실 추출은 AST·Symbol·Route·API·DTO·기존 테스트에서 결정론적으로 한다.
3. LLM은 요약·설명·후보 추천만 하고, 근거 없는 Endpoint/기대값을 확정하지 않는다.
4. LLM 출력은 JSON Schema 검증을 통과해야 저장한다.
5. 통합 FE step은 **agent-browser MCP** 기본 경로를 쓴다.
6. MCP 사용 전 사용자에게 문의한다. 무단 파괴적 크롤 금지.
7. Pass/Fail·배포는 단정하지 않는다. 관측 요약과 `missing_data`만 남긴다.
8. 임의 `sleep` 대신 조건 대기(snapshot/selector/network)를 쓴다.
9. 메뉴 기능·Route·API·Workflow가 바뀌면 `docs/08.메뉴와워크플로우/`를 같은 변경에 포함한다.
10. Agentic 실행은 `PlatformRunnerAdapter → AgentRuntime`을 경유한다. service에서 모델 선택·Skill 실행을 복제하지 않는다.
