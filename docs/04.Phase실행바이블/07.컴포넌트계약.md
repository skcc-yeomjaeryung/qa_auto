# Phase 07 — Frontend 컴포넌트 필수속성·Locator·바인딩 계약 생성

## 이 프롬프트의 역할

당신은 대형 SI 프로젝트용 AI Code-to-E2E 관통 테스트 플랫폼의 수석 개발자다.  
프로젝트 루트에서 먼저 다음 문서를 읽고 현재 코드 상태를 점검하라.

- `AGENTS.md`
- `README.md`
- `index.md`
- `00_common_context.md`
- `00_pilot_definition_of_done.md`
- 관련 JSON Schema와 이전 Phase 완료 보고서

계획 문서만 작성하지 말고, **실제 구현·테스트·문서화·완료 보고까지 한 번의 작업으로 수행**하라.  
모호한 부분은 기존 코드와 공통 문서를 근거로 합리적인 기본값을 채택하고, 구현을 중단하는 질문으로 돌리지 말라.

## Phase 목표


시나리오가 사용하는 A/B 화면 컴포넌트의 필수 속성, 데이터 제약, 실제 이벤트, 안정적 Locator, B 화면 바인딩 대상을 Input/Output Contract로 확정한다.

## 상세 구현 요구사항


1. A 화면 입력마다 다음을 생성한다.
   - logical name
   - semantic type 후보
   - HTML/Custom component type
   - required
   - type/format/pattern/min/max/enum
   - default value
   - events: input/change/blur/submit
   - locator 우선순위
2. Locator 우선순위:
   1) `data-testid`
   2) accessible role+name
   3) label
   4) stable id/name
   5) CSS/XPath는 최후 수단
3. Custom SI Component를 매핑하는 Adapter SDK와 YAML 설정을 제공한다.
4. B 화면 출력마다 response JSONPath, UI locator, normalize rule을 연결한다.
5. Screenshot 촬영 지점과 마스킹 대상 영역을 계약에 포함한다.
6. Frontend와 Backend validation 차이를 Contract에 표시한다.
7. Locator가 불안정하면 자동 확정하지 말고 Warning을 표시한다.
8. `structuredOutput`, Zod, TypeScript type, existing test fixture를 입력원으로 사용할 수 있게 한다.
9. 사용자에게는 전체 속성이 아니라 필수·불확실 항목을 우선 표시한다.
10. Design Spec annotation이 있으면:
    - 번호·컴포넌트명을 logical name / semantic type **힌트**로만 사용한다.
    - Locator·required·format은 코드/테스트 Evidence가 우선이다.
    - annotation에만 있고 DOM/코드에 없으면 `missing_data`로 표시하고 추정하지 않는다.


## API·계약·데이터


Input Contract 예시:

```json
{
  "field": "customerId",
  "required": true,
  "type": "string",
  "pattern": "^C[0-9]{5}$",
  "semanticType": "customer_identifier",
  "locator": {
    "strategy": "testId",
    "value": "customer-id"
  },
  "events": ["fill", "blur"],
  "sources": []
}
```

Output Binding Contract 예시:

```json
{
  "responsePath": "$.riskLevel",
  "uiLocator": {"strategy":"testId","value":"risk-level"},
  "normalize": ["trim", "uppercase"]
}
```


## UI 요구사항


시나리오 상세에서 A와 B 카드를 제공한다.

- A: 입력명, 필수, 형식, 추천값 준비 상태, Locator, 이벤트
- B: 응답 경로, 표시 컴포넌트, Binding, Assertion
- 불안정 Locator와 Validation 불일치 경고
- Screenshot preview는 이후 실행 후 채운다.
